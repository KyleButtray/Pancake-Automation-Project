# MME 305 – Pancake Automation Project

Designed an app within MATLAB environment to automate the process of controlling and interfacing the app with a loadcell, thermocouple, pancake griddle, and blender so that pancake batter was measured accurately and pancake was cooked perfectly every time. App was designed to be user friendly and was tested by friends and faculty. Created wiring and loop diagrams to easily reconstruct circuitry if needed.

## Projects Elements

| Folder | What it is | Description |
|---|---|---|
| `Pancake Automation Project/` | "Ship of Theseus" project (MATLAB App), pancake manufacturing + load cell + thermocouple calibration data, images, final report PDF | The idea behind this project is using a an app to automate and control the making of a pancake. This involves accurately weighing ingredients with a loadcell, setting a time and temperature for a pancake griddle using a thermocouple, and intuitively guiding the app user through the process of making the pancake.|
| `Calibration files/` | NI DAQ analog-read / exported CSV data | Data acquired from calibration of load cell and thermocouple which was used to get accurate readings from both sensors |
| `Pancake_wiring/` | Visual of wiring used in project | Used to power all sensors and relays as well as reading sensor outputs to the DAQ |
| `PancakeManufacturingData/` | Data from running project | Final Testing Data of loadcell and thermocouple throughout making a pancake |
| `W9_W12_Course Project_Description/` | Project Description | Further description of project requirements |

## Tools used
MATLAB (incl. App Designer), NI data acquisition hardware, Excel
